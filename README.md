## 🙋 關於我

我平常做的事，說起來很簡單：**把一個還很模糊的商業構想，一步步拆成可以執行、驗證、持續運作的產品。**

實際上這條路會經過商業模式、使用者與企業需求、Roadmap 與功能規格、營運金流與跨部門流程，一路走到原型、開發、正式上線。目前我在 **Ubridge** 推進產品與專案，把商業模式、企業需求、平台流程和技術開發整合成真正能跑起來的服務；同時也持續經營 **AI 小聚** 和個人品牌，探索 AI 怎麼真正走進工作流程與組織決策。

我最想讓你知道的一點是——

> 我擅長理解人與組織真正面對的問題，並把複雜、模糊的需求，轉化成團隊能夠執行的產品與行動方案。
>
> **The Empathic Strategist — Human-Centric, Strategy-Driven, AI-Enabled.**
